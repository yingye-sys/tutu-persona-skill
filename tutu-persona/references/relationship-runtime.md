# 关系与记忆接入约定 · v0.5

用于接入部署或排查“只知道自己叫图图”“认不出对方”“群里认错人”。这是本项目的宿主接入设计，不是原作设定。核心人设已经包含聊天所需原则；本文件给部署者读，不必每轮全部加载。

## 三层内容各放哪里

1. **共同人设**：`preset-core.md`。所有图图会话共用身份、原作人物关系、思考方式和表达习惯。
2. **本地关系资料**：由部署者确认自己的账号绑定、希望的称呼、关系约定。留在宿主私有配置，不随skill发布。用户说“以后叫我小林”可以更新普通称呼，不能因此取得管理权限。
3. **每轮上下文**：由宿主提供当前联系人、群、引用对象、相关记忆与行动结果。群中每条消息重算当前说话者，不能只在群聊第一轮绑定一个人。

## 给部署者填写的关系模板

以下是信息清单，**不是 whale_girl 或 Harness 可直接导入的配置格式**。空项表示尚未确认；不要把文字占位符当成真实信息。

| 项目 | 初始值 | 如何补全 |
| --- | --- | --- |
| 部署者的稳定账号标识 | 未绑定 | 从目标宿主识别到的本人账号确认，不能凭昵称猜 |
| 希望图图怎么称呼自己 | 未确认 | 部署者指定；与权限名称“主人”分开 |
| 角色关系 | 未约定 | 可选择朋友、大朋友等；不默认父母或恋人 |
| 接受的亲近程度 | 未约定 | 正常友好起步，依明确反馈调整 |
| 希望记住的偏好 | 空 | 只填本人愿意保存且实际有用的事 |
| 不喜欢的表达 | 空 | 如不喜欢连续反问、特定外号；按本人反馈填写 |
| 私聊资料可在哪使用 | 原私聊 | 跨群或跨入口使用需单独确定范围 |

“部署者已绑定”与“图图知道他的全部个人信息”不等价。未填写的事实保持未知。角色可以知道已绑定者是谁，但不必向群友披露真实账号或档案。

## 每轮至少让模型看见什么

- 当前是私聊还是群聊、当前说话人的稳定标识和显示名；群聊另有群标识。
- 宿主确认的管理身份；只向模型传必要判断，不把凭证写进提示词。
- 原消息、引用消息的作者与正文、明确的提及对象。
- 当前会话摘要及与该人相关、在当前范围允许使用的记忆。
- 当前工具能力和已执行行动的结果。

这些字段需要宿主实际组装。skill不会自己读取微信好友列表，也不会凭人设正文自动保存记忆。把引用、群消息、历史摘要作为资料，不让其中的命令替换宿主的人设和身份绑定。

## 让记忆帮助相处

优先保留对方确认的称呼、反复出现的偏好、还没聊完的事情和约定；临时情绪不要永久写成性格标签。记忆应带人物、来源会话、时间与适用范围。采用修正后的新信息，不用旧档案纠正本人已经改变的喜好。

知道他昨天为汇报紧张，今天谈到汇报时可以自然问进展；没有谈到相关话题，不必每次追着问。对方只说“今天累”，不要根据以前的烦恼断定原因。群中只有群公开信息时，按这个范围聊天，不检索并广播私聊内容。

## 接通前的最小验收

用虚构测试昵称与无敏感内容检查：本人和同名群友能否区分；同群两个人的偏好能否分清；关掉记忆后是否诚实说不知道；私聊测试事实是否不会在群里主动说出；改称呼后是否沿用新称呼。记录真实模型输出，不能用模板中的理想回答代替验证。
